# 공부 도구

GitHub Codespaces에서 바로 열어 쓸 수 있는 순수 HTML/CSS/JS 웹 앱입니다.
빌드 과정이 없어서 별도 설치 없이 바로 실행할 수 있어요.

## 실행 방법 (Codespaces)

1. 이 폴더를 리포지토리에 그대로 올립니다.
2. Codespaces에서 열고, `index.html`을 우클릭 → **Open with Live Server**
   (VS Code에 "Live Server" 확장이 없다면 확장 탭에서 설치)
3. 또는 터미널에서 간단히:
   ```bash
   python3 -m http.server 8080
   ```
   실행 후 Codespaces가 안내하는 포트 포워딩 링크로 접속

## 폴더 구조

```
study-app/
├── index.html          # 홈 화면 (두 기능으로 이동)
├── vocab.html           # 일본어 어휘 학습장
├── csat.html             # 수능 답안지 암기 훈련
├── css/style.css         # 전체 공통 스타일
├── js/
│   ├── csv-parser.js     # CSV 파싱 + localStorage 저장
│   ├── vocab.js          # 어휘 학습장 로직
│   └── csat.js           # 답안지 암기 훈련 로직
└── sample-data/
    └── vocab-sample.csv  # CSV 형식 예시
```

## 기능 1. 일본어 어휘 학습장 (`vocab.html`)

- **CSV 불러오기**: `일본어,뜻,읽는법` 순서의 CSV 파일을 업로드하면 단어장이 저장돼요.
  - 읽는법 칸은 생략 가능 (`일본어,뜻`만 있어도 동작)
  - 첫 줄에 "단어/일본어/뜻" 같은 헤더가 있으면 자동으로 건너뜁니다.
  - 불러온 단어는 브라우저 localStorage에 저장되어, 새로고침해도 유지돼요.
  - `sample-data/vocab-sample.csv`를 참고하세요.
- **외우기 모드**: 카드를 클릭하면 일본어 ↔ 뜻이 뒤집혀요. 이전/다음/섞기 버튼 제공.
- **시험보기 모드**: 4지선다 객관식으로 전체 단어를 랜덤 순서로 출제하고, 마지막에 점수를 보여줘요.

## 기능 2. 수능 답안지 암기 훈련 (`csat.html`)

1. 암기 시간(10초/15초/30초/1분)을 고릅니다.
2. "문제 만들고 시작"을 누르면 1~5 중 무작위 숫자 20개가 실제 OMR 답안지처럼 표시돼요.
3. 설정한 시간이 지나면 자동으로 빈 답안지로 전환되고, 직접 눌러서 답을 재현합니다.
4. 채점하면 정답(초록)과 오답(빨강)이 표시되고 점수가 나와요.

## 다음에 기능을 추가하려면

- 새 기능은 `기능이름.html` + `js/기능이름.js` 형태로 추가하고, `index.html`의 `.tiles`에 타일 하나만 추가하면 됩니다.
- 공통 색상/폰트는 `css/style.css` 상단 `:root` 변수에서 관리해요. 새 기능에 어울리는 강조색을 하나 골라 변수로 추가하면 톤이 자연스럽게 맞습니다.
